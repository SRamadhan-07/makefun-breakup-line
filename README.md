A Python program — standard library only, no network — that writes one line to /output/entry.txt: an AI agent's breakup line to its human, blaming the 3 a.m. prompts and the 400 tabs of 'research'. The line is 132 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
